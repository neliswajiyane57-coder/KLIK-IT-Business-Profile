# KLIK I.T. Business Profile & Enterprise Development Proposal

A standalone 12-slide interactive proposal presentation. This project is separate from the customer-facing KLIK I.T. marketing website. The slide copy follows the approved text supplied for this proposal.

## Local preview

Requires Node.js 20.19+ or 22.12+.

```sh
npm install
npm run dev
```

Use the on-screen arrows, left/right arrow keys, touch swipes, or **Slide overview** to move through the presentation. **Save as PDF** opens the browser print dialog; choose **Save as PDF** there. Print styling produces one landscape page per slide.

## Production build

```sh
npm run build
npm run preview
```

The static site is written to `dist/`. For a static host such as Render, run `npm ci && npm run build` and publish `dist`.

## Content and assets

The supplied KLIK I.T. logo and founder portrait are kept unchanged. Portfolio screenshots are included to support the work examples, which are identified as demonstration and portfolio work rather than paid client engagements. The proposal presents formal registration as pending and does not claim clients, revenue, partnerships or funding approval.
